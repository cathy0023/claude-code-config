### ES（新索引 + reindex）

```bash
# 创建 v2
curl -X PUT "http://{ES_HOST}:9200/megaview_conversation_v2" -H 'Content-Type: application/json' -d '{
  "mappings": {
    "properties": {
      "conv_id": {"type": "keyword"},
      "user_id": {"type": "long"},
      "score": {"type": "float"},
      "export_flag": {"type": "boolean"}
    }
  }
}'

# reindex（异步）
curl -X POST "http://{ES_HOST}:9200/_reindex?wait_for_completion=false" -H 'Content-Type: application/json' -d '{
  "source": {"index": "megaview_conversation_v1"},
  "dest": {"index": "megaview_conversation_v2"}
}'

# 切 alias
curl -X POST "http://{ES_HOST}:9200/_aliases" -H 'Content-Type: application/json' -d '{
  "actions": [
    {"remove": {"index": "megaview_conversation_v1", "alias": "megaview_conversation"}},
    {"add": {"index": "megaview_conversation_v2", "alias": "megaview_conversation"}}
  ]
}'
```

**验证**：
```bash
GET http://{ES_HOST}:9200/_cat/indices/megaview_conversation_v2?v   # 文档数与 v1 一致
GET http://{ES_HOST}:9200/_alias/megaview_conversation               # 指向 v2
```

### MQ（新 topic）

```bash
kafka-topics.sh --bootstrap-server {KAFKA_HOST}:9092 --create \
  --topic megaview-export-task-v2 --partitions 8 --replication-factor 3
```

**验证**：`kafka-topics.sh --list --bootstrap-server {KAFKA_HOST}:9092 | grep export-task-v2`

### Redis（双写）

通过 ④ 部署的代码自动生效（新代码同时写 `export:task:{id}` 和旧 key）。无手动操作。

**坑**：reindex 没等完就切 alias → 丢数据；Kafka topic 没创建 → 生产者发送失败主流程挂。
